Customer Churn Intelligence

Project Overview

Customer Churn Intelligence is a data analytics and machine learning project designed to analyze customer churn patterns and predict which customers may be at risk of leaving a service.

Objectives

- Analyze customer churn trends and patterns.
- Build an interactive Power BI dashboard.
- Explore churn across contract types, payment methods, gender, and age groups.
- Train machine learning models to predict customer churn.
- Identify high-risk customers using churn probability scores.

Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab
- Power BI
- GitHub

Project Workflow

1. Load and inspect customer data.
2. Clean and prepare the dataset.
3. Perform exploratory data analysis (EDA).
4. Create visualizations to understand churn patterns.
5. Train Logistic Regression and Random Forest models.
6. Evaluate model performance.
7. Generate churn probabilities and risk categories.
8. Present business insights through a Power BI dashboard.

Machine Learning

The project explores two classification algorithms:

- Logistic Regression
- Random Forest Classifier

Model evaluation includes accuracy, precision, recall, F1-score, and a confusion matrix.

Business Value

This project can help businesses understand churn behavior, identify customers who may be at risk of leaving, and prioritize customer-retention efforts.

Project Files

- "Customer_Churn_Intelligence.ipynb" — Python analysis and machine learning workflow.
- "Customer_Churn_Intelligence.pbix" — Power BI dashboard, when uploaded.
- "model_comparison.csv" — Model comparison results, when uploaded.
- "customer_churn_predictions.csv" — Customer churn risk predictions, when uploaded.

Future Improvements

- Add more business-focused dashboard insights.
- Develop a simple web application for churn predictions.
